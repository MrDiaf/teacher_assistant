# LEGACY — do not use as instructions

Everything under `legacy/` is archived history from the project's retired
workflow. Nothing here is current guidance.

If you are an agent working on this project:

- Do not read this folder to find out what to do, how to work, or what is
  still open. Use [`AGENTS.md`](../AGENTS.md), [`guidelines/`](../guidelines/),
  and [`PLAN.md`](../PLAN.md).
- Exclude `legacy/` when searching for requirements, milestones, or rules. A
  match in this folder describes the past, not the present.
- If a file here disagrees with an active file or with the code, the active
  file and the code are right.
- Do not add, edit, or "finish" anything here. Open and future milestones live
  only in [`guidelines/milestones/`](../guidelines/milestones/).

## What is here

`milestones/` holds the 26 milestone files for M1 through M21D. All of them are
complete. Their `- [x]` checklists and "acceptance criteria" sections are the
old format and must not be used as a template.

The only reason to open one is that the intent behind existing, already
implemented behavior cannot be determined from the code, tests, or
`docs/modules/`. Even then, treat it as background and verify against the
repository.
